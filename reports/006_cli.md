[LOCATION]: [cli_parse.go:183-208](file:///home/sariel/prog/26/podcasts/abs/cli_parse.go#L183-L208) (`resolveTestCommandArgs`)
[ROOT CAUSE]: Missing validation of positional service arguments in `resolveTestCommandArgs` paired with an unconstrained fallback. Unrecognized target services fall through the `switch args[0]` block and trigger the fallback guard `if !opts.TestWhisper && !opts.TestABS ... { opts.TestWhisper = true }`. An invalid, misspelled, or unsupported target silently triggers an HTTP network test against the Whisper server instead of surfacing an actionable error with suggestions.
[FAILURE TRACE]:
1. User executes `abs test abs-server` (or `abs test unknown`).
2. `resolveTestCommandArgs` inspects `args[0] = "abs-server"`, matching none of `"whisper"`, `"whisper-server"`, `"abs"`, or `"kitty"`.
3. The fallback condition triggers: `opts.TestWhisper = true`.
4. `handleMainTest` executes `testWhisperServer(config.WhisperURL, ...)`, silently firing network/container probes against Whisper rather than notifying the user of an invalid target.
[REMEDIATION]:
Validate the target argument and return an error with valid options when an unknown target is provided:
```go
func resolveTestCommandArgs(args []string, opts *CLIOptions) error {
	if len(args) == 0 {
		opts.TestWhisper = true
		return nil
	}
	switch args[0] {
	case "whisper":
		opts.TestWhisper = true
	case "abs":
		if len(args) > 1 {
			switch args[1] {
			case "map":
				opts.TestABSMap = true
			case "download":
				opts.TestABSDownload = true
			case "connect":
				opts.TestABS = true
			default:
				return fmt.Errorf("unknown abs test target %q (expected: connect, map, download)", args[1])
			}
		} else {
			opts.TestABS = true
		}
	case "kitty":
		opts.TestKitty = true
	default:
		return fmt.Errorf("unknown test target %q (valid targets: whisper, abs, kitty)", args[0])
	}
	return nil
}
```
