# Usage Message Audit Report — mail_cli issues only

Generated by testing `clihelp` rendering at terminal widths 60, 80, and 100 across all commands and subcommands (~80 command paths).

Library-level issues (OSC 8 stripping, title reflow, width cap inconsistency) are documented separately in `clihelp_fix.md`.

---

## Issue 1: Title line overflows at narrow width

**Observed:** `mail_cli account associate --help` at width 60:
```
Detailed Usage: account associate <account_name> <program_name>
```
The line is 63 visible chars (69 with ANSI codes), overflowing the 60-char width by 3+ chars.

**Root cause:** The `Title` field in `cli/accounts.go:70` is too long:
```go
Title: "account associate <account_name> <program_name>",
```
This gets prefixed with `"Detailed Usage: "` (16 chars) for a total of 69 chars.

**Fix:** Shorten the Title to `"account associate <name> <program>"` — this saves 12 chars and brings it under 60.

**Affected:** Only `accounts associate`.

---

## Issue 2: Missing Title on most subcommands

**Observed:** Many deeply nested subcommands show only their bare name as the header title instead of the full command path.

| Command | Title shown | Expected |
|---------|-------------|----------|
| `rule list` | `list` | `rule list` |
| `rule delete-all` | `delete-all` | `rule delete-all` |
| `rule update` | `update` | `rule update` |
| `rule export` | `export` | `rule export` |
| `spam del` | `del` | `spam del` |
| `spam bye` | `bye` | `spam bye` |
| `spam learn` | `learn` | `spam learn` |
| `spam pol` | `pol` | `spam pol` |
| `labels list` | `list` | `labels list` |
| `labels cache` | `cache` | `labels cache` |
| `labels list full` | `full` | `labels list full` |
| `calendar add-all` | `add-all` | `calendar add-all` |
| `unspam folder` | `folder` | `unspam folder` |
| `learning reset` | `reset` | `learning reset` |

Compare with commands that DO have a proper `Title`:
- `rule add <email> <lbl>`
- `rule del <email|title>`
- `account associate <account_name> <program_name>`
- `config set <key> <value>`
- `cache prune [days] [--wipe]`
- `labels rename <old_name> <new_name>`

**Fix:** Add a `Title` field to every subcommand that shows the full command path. This is already the established pattern for well-dressed commands. The Title should be kept under ~44 chars to avoid overflow at width 60 (until clihelp's title reflow fix is in place).

**Affected files:** `cli/rules.go`, `cli/spam.go`, `cli/labels.go`, `cli/calendar.go`, `cli/misc.go` (unspam, learning), and potentially others.
