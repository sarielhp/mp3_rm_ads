# mail\_cli labels del

Delete a label/folder from the server.

## Usage

```
mail_cli labels del <lbl_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<lbl_name>` | The full path of the label to delete. |

## Examples

- `mail_cli labels del Receipts/Old`
