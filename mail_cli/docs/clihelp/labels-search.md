# mail\_cli labels search

Search cached labels by one or more substring patterns (all must match).

## Usage

```
mail_cli labels search <substring> [additional_substrings...]
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<substring>` | Substring to search for in folder paths. |

## Examples

- `mail_cli labels search receipts`
- `mail_cli labels search archive 2026`
