# mail\_cli download

Download all messages in the specified label (which must match a unique label) to a local mbox file.

## Usage

```
mail_cli download <label> <file_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<label>` | The unique label/folder to download messages from. |
| `<file_name>` | The local mbox destination file path. |

## Examples

- `mail_cli download receipts ~/archive/receipts.mbox`
