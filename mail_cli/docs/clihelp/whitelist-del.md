# mail\_cli whitelist del

Remove one or more email addresses from the whitelist.

## Usage

```
mail_cli whitelist del <email...>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<email...>` | Email addresses to remove from whitelist. |

## Examples

- `mail_cli whitelist del friend@example.com`
