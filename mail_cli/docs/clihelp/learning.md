# mail\_cli learning

Manage local spam learning and training.

## Usage

```
mail_cli learning <subcommand>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [reset](learning-reset.md) | Reset all local spam classifications and scores in the cache for the current account. |
