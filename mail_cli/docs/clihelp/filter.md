# mail\_cli filter

Manage remote filters on Gmail.

## Usage

```
mail_cli filter <subcommand>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [list](filter-list.md) | List remote server filters. |

## Examples

- `mail_cli filter list`
