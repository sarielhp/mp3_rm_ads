# mail\_cli rule list

List custom routing rules.

## Usage

```
mail_cli rule list [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-a, --all` | List all custom routing rules, including those already exported |

## Examples

- `mail_cli rule list`
- `mail_cli rule list --all`
