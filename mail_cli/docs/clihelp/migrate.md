# mail\_cli migrate

Copy configuration and credentials to a remote machine via SSH/SCP.

## Usage

```
mail_cli migrate [user@]host
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `[user@]host` | Remote destination machine address (e.g. server.local or user@server.local). |

## Examples

- `mail_cli migrate myserver.local`
- `mail_cli migrate user@myserver.local`
