# mail\_cli blacklist del

Remove one or more email addresses from the blacklist.

## Usage

```
mail_cli blacklist del <email...>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<email...>` | Email addresses to remove from blacklist. |

## Examples

- `mail_cli blacklist del spammer@example.com`
