# mail\_cli rule del

Remove an auto-labeling rule.

## Usage

```
mail_cli rule del <email|title>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<email|title>` | The sender email or subject title to remove rule for. |

## Examples

- `mail_cli rule del notifications@github.com`
