# mail\_cli account delete

Delete an existing account and its credentials.

## Usage

```
mail_cli account delete <account_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<account_name>` | The name of the account to delete. |

## Examples

- `mail_cli account delete temp-account`
