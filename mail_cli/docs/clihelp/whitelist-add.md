# mail\_cli whitelist add

Add one or more email addresses to the whitelist.

## Usage

```
mail_cli whitelist add <email...>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<email...>` | Email addresses to add to whitelist. |

## Examples

- `mail_cli whitelist add friend@example.com`
