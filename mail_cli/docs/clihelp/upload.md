# mail\_cli upload

Upload all email messages from a local mbox file to the specified target label/folder on the server.

## Usage

```
mail_cli upload <label> <file_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<label>` | The target label/folder to upload messages into. |
| `<file_name>` | The local mbox file path to read messages from. |

## Examples

- `mail_cli upload receipts ~/archive/receipts.mbox`
