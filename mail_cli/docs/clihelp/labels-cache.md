# mail\_cli labels cache

Manage the local labels cache.

## Usage

```
mail_cli labels cache <subcommand>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [update](labels-cache-update.md) | Fetch the latest labels and folder hierarchies from the server and refresh the local cache. |

## Examples

- `mail_cli labels cache update`
