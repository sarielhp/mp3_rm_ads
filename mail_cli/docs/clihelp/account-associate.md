# mail\_cli account associate

Associate a program/symlink name with an account for automatic account selection.

## Usage

```
mail_cli account associate <account_name> <program_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<account_name>` | The existing account name to associate with. |
| `<program_name>` | The command name that will trigger this account (e.g. "work_mail"). |

## Examples

- `mail_cli account associate work-account work_mail`
