# mail\_cli spam pol

Manage political spam processing and unsubscribing.

## Usage

```
mail_cli spam pol <subcommand>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [audit](spam-pol-audit.md) | Scan Spam folder for political fundraising emails and print scoring details. |
| [unsub](spam-pol-unsub.md) | Scan the Spam folder for political messages and execute unsubscription opt-outs. |

## Examples

- `mail_cli spam pol audit`
- `mail_cli spam pol unsub`
