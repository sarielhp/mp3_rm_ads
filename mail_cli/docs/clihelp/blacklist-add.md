# mail\_cli blacklist add

Add one or more email addresses to the blacklist.

## Usage

```
mail_cli blacklist add <email...>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<email...>` | Email addresses to add to blacklist. |

## Examples

- `mail_cli blacklist add spammer@example.com`
