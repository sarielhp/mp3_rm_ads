# mail\_cli labels list full nozero

List non-empty labels with their full name.

## Usage

```
mail_cli labels list full nozero [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-a, --all` | List all labels, including those with zero messages |
| `-e, --ext` | Show (unread/total) message counts |
| `--real` | Fetch real-time counts from server (bypasses cache) |

## Examples

- `mail_cli labels list full nozero`
