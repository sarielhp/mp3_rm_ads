# mail\_cli config reset

Reset a configuration parameter to its default value.

## Usage

```
mail_cli config reset <key>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<key>` | The configuration parameter name to reset. |

## Examples

- `mail_cli config reset score_threshold`
