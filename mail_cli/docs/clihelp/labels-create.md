# mail\_cli labels create

Create a new label or folder path on the server.

## Usage

```
mail_cli labels create <lbl_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<lbl_name>` | The name or path of the label/folder to create. |

## Examples

- `mail_cli labels create "Work/Projects"`
